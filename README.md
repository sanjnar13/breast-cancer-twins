# Breast Cancer Hazard in Twin Groups
This code was used to compare breast cancer incidence rates in different types of twins in order to ascertain the affect that prenatal and early environment factors have on breast cancer risk. This was done using a Cox proportional hazards model. 

All data necessary to reproduce the current analysis are available following procedures described on the Sister Study website (https://sisterstudy.niehs.nih.gov/English/data-requests.htm). Approval is required to access the data, as such the results are not published in this repository. Furthermore, the manuscript is still under review for this.
